# Upstream source

Ovren by Licht continues the open-source desktop application formerly released as Wyre. The app in [`app/`](app/) is built on [MangoDisk](https://github.com/harry0703/MangoDisk) by harry0703 and contributors, version 1.1.9 at commit `f7d8bc73b68ec2170ac4ba451c6723b11329380c`. MangoDisk is licensed GPL-3.0-only. Its license is kept at [`app/LICENSE`](app/LICENSE), and the combined application is distributed under GPL-3.0-only.

Ovren keeps MangoDisk's storage, cleanup, privacy, application, startup, system optimization, maintenance and history features. The previous Wyre version added native network measurement, native Windows and GNOME pointer controls, and the macOS-style interface. Interface symbols are sourced from [SFStudio](https://github.com/lylicht/SFStudio); SF Symbols remain Apple's property and are not used in Ovren's logo or app icon.

The earlier Wyre implementation was authored by bxane. Ovren's rebrand and ongoing maintenance are by Licht; original MangoDisk, Wyre, and third-party credits are retained.

To compare the original desktop source, check out the commit above from the MangoDisk repository.
